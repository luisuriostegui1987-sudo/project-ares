# ARES Research Note template (ARES-010) + Thesis schema (Constitution Sec 8)

## RESEARCH NOTE
1. Question:            <one crisp sentence>
2. Evidence we have:    <Fact objects: value · unit · source · date · RULE 17 class>
3. Evidence missing:    MISSING: <fact>
4. Assumptions:         <stated openly so they can be attacked>
5. Analysis:            <base rates first; reason over facts, never memory>
6. Confidence:          <RULE 17 class + 0-100; falls as MISSING rises>
7. What would invalidate: <the price/event that proves us wrong>
8. Research next:       <highest-value open question>

## THESIS (only if the note supports one)
- Asset / entity
- Thesis summary (<= 5 sentences)
- Hypothesis (one testable central claim)
- Bull case / Base case / Bear case (bear is MANDATORY, steel-manned)
- Catalysts (dated where possible)
- Invalidation conditions (MANDATORY)
- Time horizon (2W / 1M / 3M / up to 6M)
- Scores (Evidence Quality, Probability, Confidence, Asymmetry — deterministic)
- Risk result (verdict + recommended paper size) — from the risk engine
- Information-imbalance statement: "The market expects ___, but the evidence suggests ___."
- Position size: 0 (watchlist) unless a real, defensible edge exists.

This is research, not personalized financial advice. Only the human decides.
