# AI-first conversational interface

**Status**: authorized direction — not scheduled, not started.

Natural-language access to ARES research WITHIN governance: the assistant may retrieve, summarize and cite governed artifacts, and may never fabricate facts, upgrade confidence, or express capital recommendations. Every answer traces to fact/report ids.

Governance: any implementation follows the standard flow (branch → PR → CTO/CRO review → Luis authorizes merge).
