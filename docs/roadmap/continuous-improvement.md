# Permanent continuous improvement

**Status**: authorized direction — not scheduled, not started.

A standing principle, not a phase: every sprint ends with review gates; every gap found becomes a recorded item; methodology and code both follow Draft→Reviewed→Active lifecycles; nothing is considered finished — only currently unimproved.

Governance: any implementation follows the standard flow (branch → PR → CTO/CRO review → Luis authorizes merge).
