# ARES OS

**Status**: authorized direction — not scheduled, not started.

The unifying product vision: ARES as a coherent research operating layer — one governed core (facts, reports, methodology) surfaced through every device and interface below. All surfaces consume the institutional API as the single entry point; governance (RULE 17, append-only stores, human capital decisions) is identical everywhere.

Governance: any implementation follows the standard flow (branch → PR → CTO/CRO review → Luis authorizes merge).
